# DEMO Frontend

Frontend DEMO, una plataforma administrativa para la gestión de módulos, operaciones y procesos empresariales.

El proyecto está desarrollado con **Angular** siguiendo una arquitectura modular orientada a escalabilidad, mantenibilidad y control de permisos.

---

# Tecnologías utilizadas

- Angular
- Angular Material
- TypeScript
- SCSS
- RxJS
- JWT Authentication

---

# Características principales

- Arquitectura modular basada en **Core, Features y Shared**.
- Sistema de **autenticación con JWT**.
- Control de **permisos y protección de rutas**.
- Manejo de **sesión e inactividad del usuario**.
- **Layout administrativo** con sidebar y topbar.
- Navegación dinámica basada en configuración.
- **Tema visual personalizado** sobre Angular Material.
- Componentes reutilizables y escalables.
